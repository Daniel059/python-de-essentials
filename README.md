# Python Essentials for Data Engineers: My Learning Project

A hands-on data pipeline project covering Extract, Transform, Load,
data quality checks, testing and orchestration in Python.

This project was built while following Joseph Machado's tutorial
["Python Essentials for Data Engineers"](https://www.startdataengineering.com/post/python-for-de/)
on [Start Data Engineering](https://www.startdataengineering.com/).
The learning path is inspired by his work; all code in this repository
was written by me, with modifications noted below.
